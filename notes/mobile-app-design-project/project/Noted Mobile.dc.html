Backlinks and the shape of thought
#writing + tag

Folders make you decide where a thought belongs before you know what it is. wikilinks let you defer that: write the link, resolve the note later.

What the index actually holds

One entry per file — title, tags, outgoing links, mtime — plus the inverted graph, built once at boot and patched per save.

•Reads never touch disk
•Backlinks are inverted at build time, not per request
