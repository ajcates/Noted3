A field guide to noted, drawn in Material 3 Expressive

Five seed colors, a serif with some wonk in it, shapes that morph, and motion with real spring in it — assembled here specifically for a self-hosted markdown wiki, not as a generic Material poster. Every token on this page is live CSS: your system theme already changed it once.

01 — Color

One seed, a full tonal ramp, and roles instead of hex codes

Expressive still runs on M3's tonal-role system — you never write a raw color into a component, you write primary or surface-container-high. What's new is the confidence: tertiary carries real weight instead of sitting in reserve, and containers do the work shadows used to do.

Ink — primary
Wikilinks, the caret, the primary action. It's the closest thing this app has to a brand color, so it shows up in exactly one place per screen.

02 — Type

Fraunces for the page, Manrope for the interface

Expressive's type scale is unchanged in structure — Display, Headline, Title, Body, Label, each in three sizes — but it asks for a display face with real character. Fraunces carries note titles and headings; Manrope runs the chrome, labels, and body copy where legibility at small sizes matters more than personality. A sixth, unofficial role — Source — covers raw markdown and file names.

04 — Motion

Springs, not durations

Expressive replaces fixed easing curves with spring physics — objects overshoot and settle rather than ease to a stop. Press each button; the left one carries real bounce for a primary action like "new note," the right one stays composed for something quieter like "save."

Expressive spring

High energy, visible overshoot — reserved for the one action per screen you want noticed.

Standard spring

Calm, controlled, low overshoot — everything else: save, close, navigate.

05 — Surface

Elevation is a color now, not a shadow

Expressive drops drop-shadows almost everywhere in favor of five container tones. A dialog doesn't float above the page — it's just a lighter (or darker) tone of the same paper.

07 — Tokens

Ready to paste into noted's stylesheet

The exact custom properties this page runs on — five seeds, relative-color-syntax containers, and the surface stack. Drop this at the top of the app's CSS and build every component against the roles, never a raw value.

:root {
  /* five seeds */
  --seed-ink:   oklch(52% 0.19 275);
  --seed-moss:  oklch(58% 0.08 175);
  --seed-ember: oklch(68% 0.15 55);
  --seed-alert: oklch(55% 0.20 25);
  --n-hue: 275;

  /* roles, derived — swap to Material Theme Builder output 1:1 if you ever need HCT parity */
  --primary: var(--seed-ink);
  --primary-container: oklch(89% 0.045 275);
  --on-primary-container: oklch(24% 0.10 275);

  --surface: oklch(98% 0.004 var(--n-hue));
  --surface-container-low: oklch(96.2% 0.005 var(--n-hue));
  --surface-container-high: oklch(91.5% 0.007 var(--n-hue));

  --radius-lg: 1rem;    /* note cards */
  --radius-xl: 1.75rem; /* sheets, dialogs */
  --radius-full: 999px; /* tags, search, FAB */

  --font-display: "Fraunces", ui-serif, Georgia, serif;
  --font-body: "Manrope", system-ui, sans-serif;
  --font-source: "IBM Plex Mono", ui-monospace, monospace;
}
